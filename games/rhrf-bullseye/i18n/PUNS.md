# Реестр каламбуров (вне кода)

Комментарии в диалогах запрещены. Намерение двойного дна держится здесь.
Формат: язык / сцена / строка-якорь / суть.

## stable (peg = якорь привязки AND якорь-закрепление)
- ru stableArrival "держим курс один к одному" — peg 1:1; "один к нулю" — depeg
- ru stableArrival "рвут якорь, а не просто колют камень" — якорь = peg/anchor
- ru stableArrival "преждевременный выход = ликвидация" — выход из укрытия AND exit позиции
- ru stableThanks "Якорь держится!" — anchor/peg holds
- ru stableDeparture "Peg держит тех, кто держит peg" — позывной AND термин
- en/cs/uk — те же узлы, сохранены дословно
